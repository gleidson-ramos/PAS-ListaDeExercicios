# 📚 PAS - Lista de Exercícios 
Repositório destinado à organização das atividades, exercícios, roteiros e diagramas desenvolvidos durante a disciplina de Projeto Avançado de Sistemas.

O principal objetivo deste repositório é centralizar os materiais produzidos ao longo das atividades da disciplina, mantendo uma organização por:

- Roteiros de exercícios;
- Implementações dos exercícios;
- Diagramas e representações visuais;
- Estruturas de projetos desenvolvidas durante as atividades.

### 📊 Diagramas
A pasta diagramas contém representações visuais relacionadas aos exercícios e roteiros. Os arquivos estão armazenados no formato PNG, permitindo visualizar as soluções e representações elaboradas durante as atividades.

## ☕ Projeto Java
A pasta **padroesroteiros** apresenta uma estrutura típica de projeto `Java/NetBeans`, contendo:
```bash
padroesroteiros/
├── build/
├── nbproject/
├── src/
├── build.xml
└── manifest.mf
```
O diretório src concentra as implementações dos roteiros, enquanto nbproject e os arquivos de build fazem parte da estrutura utilizada pelo projeto.
